# Подача: лендинг + три демо-меню

Лендинг услуги «QR-меню с заказом к столу» для владельцев кафе и три демо вымышленных заведений.

| Страница | Что это |
|---|---|
| `/` | лендинг |
| `/kofe/` | кофейня «Пенка»: карточки с фото |
| `/pub/` | паб «Солод»: плотный список, крупные цены |
| `/tatar/` | «Ак чәчәк», татарская кухня: журнальная колонка |

Номер стола задаётся в ссылке: `/kofe/?t=7`. В демо заказ никуда не уходит: после отправки сверху появляется карточка «Так заказ видит официант», и через пару секунд «официант» нажимает «Принял».

## Запуск

```bash
npm install
npm run dev
```

Сборка в `dist/`: `npm run build`. Пути относительные, папку можно положить в любой каталог хостинга. Открывать по адресу со слэшем на конце (`…/podacha/`), иначе не загрузятся ресурсы.

## Фото

Все фото сгенерированы моделью Z-Image-Turbo через Hugging Face (аккаунт Gazz12, PRO). Лежат в `src/assets/img/<kofe|pub|tatar>/`, подключаются полем `img` у блюда в `src/demo/venues.js`. Блюдо без `img` показывается без фото: у кофейни карточкой с подложкой, у паба и татарской кухни просто текстом.

Без фото оставлены чак-чак и талкыш калеве (модель не знает, как они выглядят, и рисует пончики), напитки на кране, гренки и пивная тарелка.
